# S-curit-des-Endpoints-et-Supervision-SIEM
Ce projet illustre l'implémentation d'une plateforme de supervision et de protection de la sécurité à travers l’utilisation de Wazuh, combinant les approches SIEM (Security Information and Event Management) et EDR (Endpoint Detection and Response). Il est déployé sur un environnement AWS avec une architecture multi-OS (Linux &amp; Windows).
