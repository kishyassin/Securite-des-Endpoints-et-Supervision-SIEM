# GitHub Repository for SIEM Lab Project

## Repository Structure Overview

```
SIEM-Endpoint-Cloud-Project/
├── README.md                          # Main project documentation
├── docs/                              # Documentation and screenshots
│   ├── siem-scenarios.md              # Detailed scenario documentation
│   ├── wazuh-dashboard-screenshots/   # Dashboard screenshots
│   ├── linux-client-screenshots/      # Linux client evidence
│   └── windows-client-screenshots/    # Windows client evidence
├── install/                           # Installation guides
│   ├── aws_setup.md                   # AWS infrastructure setup
│   ├── wazuh_install_centos.md        # Wazuh server installation
│   ├── wazuh_agent_windows.md         # Windows agent deployment
│   └── wazuh_agent_linux.md           # Linux agent deployment
├── configs/                           # Configuration files
│   ├── wazuh.yml                      # Wazuh server config
│   ├── sysmon.xml                     # Sysmon EDR config
│   └── firewall-rules.txt             # AWS security groups
└── video/                             # Video presentation
    └── link.txt                       # Classroom/YouTube link
```

## Quick Start

1. **Read the README.md** - Project overview and architecture
2. **Follow AWS Setup** - Create infrastructure (install/aws_setup.md)
3. **Install Wazuh Server** - Deploy SIEM (install/wazuh_install_centos.md)
4. **Deploy Agents** - Connect endpoints (install/)
5. **Run Scenarios** - Generate security events (docs/siem-scenarios.md)
6. **Analyze Alerts** - View results in Wazuh Dashboard
