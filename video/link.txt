## Video Upload Instructions

### Platform: Google Classroom

**Steps to Upload:**
1. Log in to your Google Classroom
2. Navigate to the assignment "Atelier Sécurité des endpoints et supervision SIEM"
3. Click "Your work"

### Video Requirements

- Key findings

## Technical Tips

### Recording Tools

**Windows**:
- OBS Studio (free, open source)
- Camtasia
- ScreenFlow
- Windows 10+ built-in screen recorder (Win + G)

**Mac**:
- QuickTime (built-in)
- OBS Studio (free)
- ScreenFlow

**Linux**:
- OBS Studio (free)
- SimpleScreenRecorder
- Kazam

### Recording Suggestions

- Use a microphone for clear narration
- Record at 1080p resolution
- Zoom in on text for readability
- Pause between sections for clarity
- Add title cards/transitions if possible
- Include timestamps in description

### Editing Tips

- Cut out dead time
- Add background music (optional, copyright-free)
- Include timestamps in YouTube description
- Add captions for accessibility
- Include your project GitHub link in description
