# Wazuh Dashboard Screenshots

## Screenshot Placeholders

This directory contains screenshots of the Wazuh dashboard showing:

1. **Overview** - Dashboard home with agent status
2. **Active Agents** - Linux and Windows clients connected
3. **Linux Alerts** - SSH brute force detection
4. **Windows Alerts** - Failed logon events
5. **Sysmon Events** - Process and network monitoring
6. **Threat Hunting** - Advanced security queries

## How to Add Screenshots

1. Take screenshots during lab execution
2. Save as PNG format (high quality)
3. Name descriptively: `01_dashboard_overview.png`, `02_active_agents.png`, etc.
4. Place in this directory
