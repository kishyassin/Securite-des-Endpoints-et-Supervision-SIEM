## Security Best Practices Implemented

✅ **Principle of Least Privilege**
   - Only required ports are open
   - Restricted source IPs where possible

✅ **Network Segmentation**
   - Separate security groups for manager and clients
   - Clients can reach manager, but not vice versa

✅ **Management Access Control**
   - SSH/RDP limited to YOUR_IP
   - Dashboard accessible only from your IP

✅ **No Direct Client-to-Client Communication**
   - Clients only communicate with manager
   - Prevents lateral movement

✅ **Encrypted Channels**
   - HTTPS (443) for dashboard
   - Encrypted agent communication (1514)

## Implementation Steps in AWS Console

### Step 1: Create Wazuh SG
1. EC2 → Security Groups → Create Security Group
2. Name: SIEM-Lab-Wazuh-SG
3. VPC: SIEM-Lab-VPC
4. Add inbound rules as specified above
5. Keep outbound as default (allow all)

### Step 2: Create Clients SG
1. EC2 → Security Groups → Create Security Group
2. Name: SIEM-Lab-Clients-SG
3. VPC: SIEM-Lab-VPC
4. Add inbound rules as specified above
5. Keep outbound as default (allow all)

### Step 3: Attach to Instances
1. EC2 → Instances
2. Wazuh-Server → Actions → Security → Change Security Groups
   - Add: SIEM-Lab-Wazuh-SG
3. Linux-Client → Actions → Security → Change Security Groups
   - Add: SIEM-Lab-Clients-SG
4. Windows-Client → Actions → Security → Change Security Groups
   - Add: SIEM-Lab-Clients-SG

## Troubleshooting Connection Issues

### If Agent Cannot Connect to Manager

1. **Check Security Group**
   ```
   AWS Console → EC2 → Security Groups
   - Verify port 1514 is open
   - Verify source is sg-clients (clients SG)
   ```

2. **Check Network ACLs**
   ```
   AWS Console → VPC → Network ACLs
   - Ensure inbound/outbound rules are not blocking 1514
   ```

3. **Test Connectivity**
   ```bash
   # From client
   nc -zv 10.0.32.10 1514
   # Should return: Connection to 10.0.32.10 port 1514 [tcp/cortex] succeeded
   ```

### If Dashboard Not Accessible

1. **Check Security Group**
   ```
   AWS Console → EC2 → Security Groups
   - Verify port 443 is open
   - Verify source includes YOUR_IP/32
   ```

2. **Test Connectivity**
   ```bash
   # From your machine
   curl -k https://<WAZUH_SERVER_IP>
   # Should return HTML (certificate warning is ok)
   ```
